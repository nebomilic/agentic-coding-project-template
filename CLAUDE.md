# Claude instructions

This repository keeps its agent instructions in [`AGENTS.md`](./AGENTS.md).

Read that file, then the nearest `AGENTS.md` to the code you are changing.

> Maintenance note: keep this file as a pointer only. Instructions duplicated
> across two files drift apart within weeks, and nobody can tell which one is
> current. If your tooling supports it, make this a symlink to `AGENTS.md`.
